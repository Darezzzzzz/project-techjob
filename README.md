# CSI401 Job Management System

**CSI401 Progress Exam Project - Job Management System for Technicians**

## 🚀 Features

### Backend API (Node.js + Express)
- ✅ **JWT Authentication System** (Register/Login)
- ✅ **Job Management System** (CRUD Operations)  
- ✅ **Swagger API Documentation** (Interactive Testing)
- ✅ **In-memory Data Storage** (Mock Database)
- ✅ **RESTful API Design** (HTTP Status Codes)

### Frontend (React + Vite)
- ✅ **React User Interface**
- ✅ **Responsive Design** (Bootstrap)
- ✅ **API Integration** (Axios/Fetch)
- ✅ **Route Management** (React Router)

## 🌐 API Endpoints

### Authentication
- `POST /api/auth/register` - User Registration
- `POST /api/auth/login` - User Login

### Job Management  
- `GET /api/jobs` - Get All Jobs
- `POST /api/jobs` - Create New Job

## 🔧 Installation & Setup

### Prerequisites
- Node.js (v16+)
- npm or yarn

### Backend Setup
```bash
cd backend
npm install
npm start
```

### Frontend Setup  
```bash
npm install
npm run dev
```

## 🌟 Usage

### Development URLs
- **Backend API**: http://localhost:5000
- **Frontend App**: http://localhost:3000  
- **API Documentation**: http://localhost:5000/api-docs
